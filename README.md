# アプリ一覧

パソコンと同じ番号・名前で、アプリを分けています。番号はアプリごとに固定し、バージョンが変わってもフォルダー名は変えません。

| フォルダー | 用途 | 起動するファイル |
|---|---|---|
| [03_アイソメ図作成](03_アイソメ図作成/) | 配管のアイソメ図を描く | `index.html` |
| [04_平面図作成](04_平面図作成/) | LPガス設備の平面図を描く | `04_平面図作成.html`（1ファイルで動作） |
| [07_LP-VISION](07_LP-VISION/) | 現場写真に設備を配置し、完成予想を作る | `LP-VISION_横バルク追加版.html`（縦バルクも使用できます） |

## アプリを使うには

1. このページ上部の「Code」→「Download ZIP」でダウンロードします。
2. ZIPを右クリックして「すべて展開」します。
3. 使いたいアプリのフォルダーを開き、上の表のHTMLファイルをChromeまたはEdgeで開きます。

GitHubでHTMLをクリックしただけでは、プログラムの内容が表示されます。作図画面は、ダウンロードして展開したファイルから開いてください。CSSやJavaScriptのファイルも同じフォルダー構成のまま保管します。

## 保存と再編集

- **03_アイソメ図作成**：「PC保存」のJSONを「開く」で読み込んで再編集します。「PDF保存」は閲覧・印刷用です。「新規作成」は左上にあります。
- **04_平面図作成**：「保存」のJSONを「開く」で読み込んで再編集します。詳しい操作はフォルダー内の説明をご覧ください。
- **07_LP-VISION**：「作業保存」の `.lpvision` ファイルを「開く」で読み込むと、写真や設備配置を復元して再編集できます。

## 保管場所と変更履歴

- **GitHubのmain**：正式なプログラムを保管する場所です。
- **パソコン**：アプリを実際に使う場所です。GitHubを更新しても、パソコンのファイルは自動更新されません。
- **コミット**：変更した日時や内容の記録です。これまでの変更履歴はそのまま残しています。

フォルダー名の変更：`Isometric_V2` → `03_アイソメ図作成`、`LPgas_V2` → `04_平面図作成`、`LP-VISION` → `07_LP-VISION`。

[平面図の単一HTML版（補助ファイル）](LPgas_V2_PDF.html)も保管しています。通常は上のアプリ一覧から選んでください。
