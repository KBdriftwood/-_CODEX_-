## 横バルク追加版（仮モデル）

[横バルク追加版HTML](LP-VISION/LP-VISION_横バルク追加版.html)

横バルクは別の単一HTMLに保存しています。縦バルク・横バルクの本体ロゴは、正面と反対面の両方に、外側から読める向きで配置しています。縦バルクの両面ロゴは両方のHTMLに反映しています。上のHTMLをダウンロードしてChromeまたはEdgeで開き、画面上部の設備選択で「横バルク」を選んで「追加」を押してください。縦バルクも引き続き使えます。

横バルクは、縦バルクと同じ緑色の本体・操作箱、承認済みの赤いマーク、「Niimi Sangyo / NewBulk」のロゴを使っています。写真・実寸の資料がないため、寸法、支持台、操作箱・配管の位置は仮です。3D回転、位置調整、追加通信なしのPNG・比較PDF保存を確認済みです。`LPgas_V2/` は別アプリで変更していません。

上部のゲージ・弁は省き、台枠のない4本脚をさらに半分の長さにして、本体も低くしました。胴体と地面の間にはわずかな隙間があります。操作箱は最初の大きさを基準に横幅を維持し、高さを1/2、出っ張りを2/3に調整しています。承認済みのロゴマークの縦横比は保持しています。

障壁は、足・台座のない板だけの形で、厚みを従来の1/4（仮寸法0.05m）にしています。障壁を選択し、下部の「前後」を開くと「障壁の透明度」の数値入力・スライダーが表示され、0%（不透明）から100%（完全に透明）まで個別に調整できます。影とPNG・比較PDFにも反映され、複製時は設定を引き継ぎます。両方のHTMLに反映済みです。

すべての設備に、下部の「前後」内の「前後位置」スライダー・数値入力と「奥へ／手前へ」ボタンを追加しています。0が基準、負の値が奥、正の値が手前です。写真上の位置・表示サイズを保ちながら重なりを変更でき、障壁の透明度と併用できます。複製では値を引き継ぎ、「初期状態に戻す」で0に戻ります。PNG・比較PDFにも反映されます。

編集画面は、上部ツールバー・中央のプレビュー・下部の操作バーで一画面に収まる構成です。下部左の選択欄、または写真上の設備をクリックして操作対象を選び、「移動／回転／前後／大きさ／カメラ」を選べます。障壁の透明度は「前後」、配管の長さ・形状は「大きさ」に表示されます。写真修復などは上部の「写真の下準備」、モデルの説明は下部の「詳細」から開けます。比較・PDF画面からは「配置に戻る」で編集を再開できます。

基礎を選んで下部の「障壁」を開くと、1辺（直線）・2辺（L字）・3辺（コの字）と取り付ける向きを選べます。「障壁を取り付ける」で、基礎上面の外周に長さを合わせた障壁が90°で固定されます。向きの「手前／右／奥／左」は基礎の回転前を基準にし、基礎と一緒に回転します。3辺では開口側を指定できます。

固定中は、基礎と障壁の移動・回転・傾き・大きさ・前後位置が連動します。障壁を選んでドラッグや数値調整をしても基礎ごと動き、透明度・障壁単体の表示・非表示の変更は個別に変更できます。基礎の表示・非表示の変更・複製・削除は固定中の障壁にも反映されます。障壁の形や向きの変更は「取り付けを更新」で反映し、不要になった辺は取り除きます。

障壁を選んだ「障壁」タブの「この障壁の固定解除」、または基礎を選んだ「全て固定解除」で、画面上の位置・向き・長さ・透明度を引き継いで自由配置に戻せます。基礎を消して障壁を残したい場合も、先に固定解除してください。固定中の障壁だけを複製すると、同じ長さ・透明度の自由配置の障壁になります。この機能は両方のHTMLで利用でき、PNG・比較PDFにも反映されます。

設備一覧に「サーモバリアFIT」を追加しています。銀色の薄いシートに、光沢と細かいしわを付けた配置イメージです。追加すると下部の「シート」が開き、1面・2面（L字）・3面（コの字）・4面（四方囲い）と向きを選べます。4面でも天井・床は開放します。「大きさ」で表示倍率・幅・高さ・奥行を、「シート」または「前後」で透明度を0%（不透明）〜100%（完全に透明）に調整できます。初期透明度は35%です。移動・回転・前後位置・表示・非表示の変更・複製は囲い全体に反映されます。

「シート」内、または上部の「写真の下準備」内の「炉の輪郭をなぞる」から、元写真の炉や残したい部分を囲めます。初期設定の「点で囲む」は、クリック／タップした位置だけを直線でつなぎ、押している間の手ぶれでは点を増やしません。置いた点はドラッグで調整できます。「なぞる」では、手ぶれ補正を「なし／弱／標準／強」から描く前に選べます。標準を初期値とし、細かな揺れをならして不要な点を減らし、大きな角や始点・終点を保ちます。拡大すると写真上でより細かく指定でき、線の終点が始点の近くに来るとぴったり合います。3点以上で囲み「囲んだ範囲を追加」、または最初の点を押して輪郭を閉じます。複数範囲の指定、拡大・縮小、1操作戻す（点の追加・点の移動・ひとなぞりを取り消す）、範囲の削除、反映前の合成プレビューも使えます。「輪郭を反映する」で編集中の有効な範囲もまとめて反映できます。「反映せず閉じる」は編集を破棄します。反映した描き方と補正の強さは、画面を開いている間、次の輪郭編集でも引き継ぎます。

囲んだ元写真の部分は、3Dの前後関係に合わせて奥のシートより手前、手前のシートより奥に合成します。「炉の前後位置」で重なりを調整しても、輪郭の写真上の位置は保たれます。手前のシートの透明度を上げると炉が透けて見えます。背景を簡易修復したり加工済み写真へ変更しても、囲んだ炉は元写真から残します。「写真の下準備」で一時的に表示・非表示を選べ、新しい元写真を読み込むと輪郭はリセットされます。合成結果はPNG・比較PDFにも反映されます。寸法・質感は配置イメージ用の仮設定です。作業内容は画面を閉じると消えるため、画像・PDFを保存してください。

PNG・PDFの保存時には「保存ファイル名」が開き、日付・ユーザー名・現場名を入力できます。ファイル名は `YYYYMMDD_ユーザー名_現場名.png`／`.pdf` です。日付は日本時間の当日を自動入力し、変更もできます。入力した名前は画面を開いている間、PNG・提案書PDF・メール添付用PDF・印刷で共有し、比較画面のユーザー名・現場名・日付とも連動します。印刷でも同じ名前を文書名に使います。ファイル名に使えない記号は `_` に置き換え、長すぎる名前は短くして、実際の保存名を画面に表示します。ユーザー名・現場名が未入力のままでは保存しません。名前の入力欄は「ユーザー名」に統一し、提案書の宛名とメール文面にも同じ名前を使います。

比較画面と提案書の表記は「完成予想」「提案書」に統一しています。
