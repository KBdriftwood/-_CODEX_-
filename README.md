## 横バルク追加版（仮モデル）

[横バルク追加版HTML](LP-VISION/LP-VISION_横バルク追加版.html)

横バルクは別の単一HTMLに保存しています。縦バルク・横バルクの本体ロゴは、正面と反対面の両方に、外側から読める向きで配置しています。縦バルクの両面ロゴは両方のHTMLに反映しています。上のHTMLをダウンロードしてChromeまたはEdgeで開き、「設備を追加・選択」で「横バルク」を選んで「追加」を押してください。縦バルクも引き続き使えます。

横バルクは、縦バルクと同じ緑色の本体・操作箱、承認済みの赤いマーク、「Niimi Sangyo / NewBulk」のロゴを使っています。写真・実寸の資料がないため、寸法、支持台、操作箱・配管の位置は仮です。3D回転、位置調整、追加通信なしのPNG・比較PDF保存を確認済みです。`LPgas_V2/` は別アプリで変更していません。

上部のゲージ・弁は省き、台枠のない4本脚をさらに半分の長さにして、本体も低くしました。胴体と地面の間にはわずかな隙間があります。操作箱は最初の大きさを基準に横幅を維持し、高さを1/2、出っ張りを2/3に調整しています。承認済みのロゴマークの縦横比は保持しています。

障壁は、足・台座のない板だけの形で、厚みを従来の1/4（仮寸法0.05m）にしています。障壁を選択すると「障壁の透明度」の数値入力・スライダーが表示され、0%（不透明）から100%（完全に透明）まで個別に調整できます。影とPNG・比較PDFにも反映され、複製時は設定を引き継ぎます。両方のHTMLに反映済みです。
