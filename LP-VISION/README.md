## 横バルク追加版（仮モデル）

[横バルク追加版HTML](LP-VISION_横バルク追加版.html)

横バルクは別の単一HTMLに保存しています。縦バルク・横バルクの本体ロゴは、正面と反対面の両方に、外側から読める向きで配置しています。縦バルクの両面ロゴは両方のHTMLに反映しています。上のHTMLをダウンロードしてChromeまたはEdgeで開き、画面上部の設備選択で「横バルク」を選んで「追加」を押してください。縦バルクも引き続き使えます。

横バルクは、縦バルクと同じ緑色の本体・操作箱、承認済みの赤いマーク、「Niimi Sangyo / NewBulk」のロゴを使っています。写真・実寸の資料がないため、寸法、支持台、操作箱・配管の位置は仮です。3D回転、位置調整、追加通信なしのPNG・比較PDF保存を確認済みです。`LPgas_V2/` は別アプリで変更していません。

上部のゲージ・弁は省き、台枠のない4本脚をさらに半分の長さにして、本体も低くしました。胴体と地面の間にはわずかな隙間があります。操作箱は最初の大きさを基準に横幅を維持し、高さを1/2、出っ張りを2/3に調整しています。承認済みのロゴマークの縦横比は保持しています。

障壁は、足・台座のない板だけの形で、厚みを従来の1/4（仮寸法0.05m）にしています。障壁を選択し、下部の「前後」を開くと「障壁の透明度」の数値入力・スライダーが表示され、0%（不透明）から100%（完全に透明）まで個別に調整できます。影とPNG・比較PDFにも反映され、複製時は設定を引き継ぎます。両方のHTMLに反映済みです。

すべての設備に、下部の「前後」内の「前後位置」スライダー・数値入力と「奥へ／手前へ」ボタンを追加しています。0が基準、負の値が奥、正の値が手前です。写真上の位置・表示サイズを保ちながら重なりを変更でき、障壁の透明度と併用できます。複製では値を引き継ぎ、「初期状態に戻す」で0に戻ります。PNG・比較PDFにも反映されます。

編集画面は、上部ツールバー・中央のプレビュー・下部の操作バーで一画面に収まる構成です。下部左の選択欄、または写真上の設備をクリックして操作対象を選び、「移動／回転／前後／大きさ／カメラ」を切り替えます。障壁の透明度は「前後」、配管の長さ・形状は「大きさ」に表示されます。写真修復などは上部の「写真の下準備」、モデルの説明は下部の「詳細」から開けます。比較・PDF画面からは「配置に戻る」で編集を再開できます。

基礎を選んで下部の「障壁」を開くと、1辺（直線）・2辺（L字）・3辺（コの字）と取り付ける向きを選べます。「障壁を取り付ける」で、基礎上面の外周に長さを合わせた障壁が90°で固定されます。向きの「手前／右／奥／左」は基礎の回転前を基準にし、基礎と一緒に回転します。3辺では開口側を指定できます。

固定中は、基礎と障壁の移動・回転・傾き・大きさ・前後位置が連動します。障壁を選んでドラッグや数値調整をしても基礎ごと動き、透明度・障壁単体の表示切替は個別に変更できます。基礎の表示切替・複製・削除は固定中の障壁にも反映されます。障壁の形や向きの変更は「取り付けを更新」で反映し、不要になった辺は取り除きます。

障壁を選んだ「障壁」タブの「この障壁の固定解除」、または基礎を選んだ「全て固定解除」で、画面上の位置・向き・長さ・透明度を引き継いで自由配置に戻せます。基礎を消して障壁を残したい場合も、先に固定解除してください。固定中の障壁だけを複製すると、同じ長さ・透明度の自由配置の障壁になります。この機能は両方のHTMLで利用でき、PNG・比較PDFにも反映されます。
