# アイソメ図 作図画面 V2

このフォルダの `index.html` をChromeまたはEdgeで開いてください。`index.html`・`sheet.css`・`sheet.js` は同じフォルダに置きます。インターネット接続や追加ライブラリは不要です。

デスクトップの「【アイソメ図作成】作図画面 V2.1.6」を基準に、このチャットで追加した新規作成機能を含めた版です。

## 保存・開く・印刷

右側のボタンは「開く」「PC保存」「PDF保存」「印刷」の順です。4つのボタンは名前の行と同じ幅に収めています。

- **PC保存**：後から再編集できるJSONファイルをダウンロードします。
- **開く**：PC保存したJSONを読み込み、続きから作図できます。
- **PDF保存**：印刷用の図面と日付・タイトル・名前を、A4横1ページのPDFとしてダウンロードします。
- **印刷**：印刷用の図面をブラウザの印刷画面に送ります。

PDFは閲覧・印刷用です。再編集する場合はJSONも保存してください。

## 新規作成

左上の「倍」の左にあるグレーの「新規作成」を押すと、配管・記号・コメントなどを消して、新しい図面を作成できます。青い方眼線は残り、最初の倍率と開始位置に戻ります。

タイトルは空、日付は当日、名前はそのまま引き継ぎます。押し間違えた場合は「戻す」で前の図面とタイトルを復元できます。必要な図面は事前にPC保存してください。

## 確認内容

ChromeでPDFデータの生成と印刷用描画、新規作成後の空の図面、名前の引き継ぎ、「戻す」による復元、新しい配管の作図を確認しました。新規作成の位置・グレーの色、通常幅と狭い画面での保存ボタンの収まりも確認しています。
