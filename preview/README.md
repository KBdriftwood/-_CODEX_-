# LP VISION 確認版の開き方

会社のWindowsパソコンで、次の手順で開けます。

1. [LP-VISION-check.zip](LP-VISION-check.zip) のファイル画面を開きます。
2. GitHubのダウンロード（下向き矢印）または「View raw」からZIPを保存します。
3. 保存したZIPを右クリックし、「すべて展開」を選びます。保存先はブラウザで指定したフォルダーです。通常はWindowsの「ダウンロード」に入ります。
4. 展開したフォルダーの `LP-VISION.html` を右クリックし、「プログラムから開く」でMicrosoft EdgeまたはGoogle Chromeを選びます。
5. サンプル背景と仮バルクが表示されたら、「写真を読み込む」から現場写真を選べます。

アプリのインストール、Webサーバー、外部サービスの登録は不要です。写真はブラウザ内で処理し、外部へ送信しません。ページを閉じたり再読み込みしたりすると編集内容は初期化されます。

## 確認できる操作

- 写真の読み込み（JPEG・PNG・WebP）
- 仮バルクの移動・回転・表示サイズの変更
- カメラの角度と遠近感の調整
- 初期状態へのリセット
- 写真と設備を合成したPNG画像の保存

寸法・色・形状は操作確認用の仮モデルです。実在製品の正確なモデルではありません。保存PNGにも仮モデルであることを表示します。

## 検証範囲

このHTMLだけを使い、追加通信を禁止したブラウザで写真・3D操作・PNG保存を検証しています。Windows実機での確認は未実施です。3D表示にはブラウザのWebGL 2が必要です。

Webサイトの公開・デプロイは行っていません。この確認版はパソコンに保存して使用するファイルです。

## 開発者向け

ソース変更後はリポジトリのルートで `npm run build:standalone` を実行し、生成された `dist-standalone/LP-VISION.html` とライセンス表記を更新してください。ZIPにも更新後の同じHTMLを入れてください。`preview` のファイルは、GitHubから取得できるように保存した確認用成果物です。
