# LP VISION 確認版の開き方

会社のWindowsパソコンで、次の手順で開けます。

1. [LP-VISION-check.zip](LP-VISION-check.zip) のファイル画面を開きます。
2. GitHubのダウンロード（下向き矢印）または「View raw」からZIPを保存します。
3. 保存したZIPを右クリックし、「すべて展開」を選びます。保存先は通常Windowsの「ダウンロード」です。
4. 展開した `LP-VISION.html` を右クリックし、「プログラムから開く」でEdgeまたはChromeを選びます。
5. 「写真を読み込む」から現場写真を選び、設備を追加・配置します。

このHTMLファイルを別のパソコンにコピーして使用できます。インストール、ログイン、ネット接続は不要です。写真を外部へ送信しません。ページを閉じたり再読み込みすると編集中の内容は消えるため、画像・PDFを保存してください。

## 使い方

- 初期表示は仮の縦バルクです。横バルクも一覧に残っています。
- 基礎、障壁、VR（ベーパーライザー）、熱源器、LPガス配管、お湯配管を追加できます。
- 配置した設備を一覧または写真上のクリックで選び、移動・回転・表示倍率を個別に調整します。数値・スライダー・ドラッグが使えます。カメラ調整は全設備で共通です。
- 配管は直線・L字・コの字と仮長さを指定できます。長さは一度消して入力し直せます。Enterキーか入力欄を離れたときに反映します。任意の経路を描いたり、機器へ自動接続したりする機能はありません。
- 長さ・形状・回転に合わせて影も変わります。影の光源は仮の固定光源です。
- 「PNG保存」で完成予想を保存します。
- 「2 比較・提案書」で、元写真と完成予想を大きく比較し、拡大できます。
- A4縦は上下、A4横は左右に写真を配置します。写真全体の縦横比を維持するため、写真によって余白が入ります。
- お客様名・現場名・題名・日付・担当者・説明文を入力し、「印刷プレビュー」で確認します。「比較ページを印刷」で印刷画面を開きます。
- 「切替提案書PDFを保存」でPDFを保存します。

寸法・形状・色はすべて操作確認用の仮モデルで、実在製品の正確な仕様ではありません。画面・PNG・比較PDFにも仮モデルであることを表示します。写真から実寸や施工可否は判断できません。

## 元写真の設備を消したい場合

「写真を簡易修復」で、写真を外部へ送らずに加工できます。

1. 「写真を読み込む」から元写真を選び、「写真を簡易修復」を押します。サンプル背景でも試せます。
2. 「修復元を選ぶ」を押し、写したいきれいな壁や地面を写真上でクリックします。
3. 消したい部分をドラッグします。修復元の模様が、その範囲に写し込まれます。
4. ブラシの大きさ・境界のぼかしを調整し、修復元を選び直しながら小さい範囲ずつ仕上げます。
5. 失敗したときは「修復を1回取り消す」（直近5回まで）か「この画面の修復をやり直す」を押します。
6. 「修復を背景に反映」で設備配置へ戻ります。「反映せず閉じる」なら加工を破棄します。

元写真は比較用に残り、修復中は3D設備を隠して写真だけを加工します。修復後の背景は縦横比を維持して長辺最大4096pxになります。

簡易修復は近くの背景を写す方式です。大きなバルクや複雑な背景では、模様の繰り返しや継ぎ目が目立つ場合があります。背景を推測して描き直すAI消去は接続していません。

別の写真アプリで設備を消して保存した画像は、「加工済み写真を読み込む」で背景にできます。先に「写真を読み込む」で元の現場写真を読み込んでください。加工時に切り抜き・余白追加・画角変更をせず、元と同じ縦横比を維持してください。背景の変更は直近5回まで戻せ、元の背景にも戻せます。比較の「現状」には加工前の元写真を使います。

## Excel・Word・図面と1つのPDFにする

1. Excelの見積書は「名前を付けて保存」でPDFを選ぶか、「印刷」でMicrosoft Print to PDFを選びます。印刷範囲・改ページを先に確認します。
2. Wordの提案書もPDF形式で保存します。図面は作成元のアプリからPDFで保存・印刷します。
3. LP VISIONの比較画面で「ほかのPDFを追加」からPDFを選びます。複数同時に追加できます。
4. 一覧の上下ボタンでファイル単位の提出順を決め、不要なものは削除します。
5. 「切替提案書PDFを保存」で1つのPDFに結合します。
6. 保存したPDFを開き、全ページの内容・順番・用紙の向きを確認してください。全体を印刷するときは、そのPDFをEdgeやAcrobatで開いて印刷します。

各PDFの元の用紙サイズ・向きを維持して結合します。比較ページは1枚の画像としてPDFに入るため、日本語は読めますが文字検索はできません。他のPDFページの文字・図形はページごとコピーします。PDFのフォーム、電子署名、しおりなどを引き継ぐ機能は対象外です。印刷用の確定したPDFを使ってください。

追加PDFは1ファイル30MB以下・20ファイルまで・合計100MB以下です。パスワード保護は解除したPDFを選んでください。PDFのページごとの抜き出し・編集はありません。

## メールで送る

「メール添付用PDFを保存」で保存したPDFを、普段のOutlookなどにご自身で添付してください。「メール作成画面を開く」は題名と本文をメールアプリへ渡すだけで、自動添付・自動送信はしません。会社の添付容量の上限も確認してください。

## 検証範囲

単一HTMLの内容だけを使い、追加通信を禁止したブラウザで写真・簡易修復・3D操作・PNG・比較PDF・PDF結合を検証しています。このクラウド環境ではファイル直接起動が管理ポリシーで禁止されているため、Windows上でのダブルクリック起動・実際のプリンター・メールアプリ連携は未確認です。WindowsのEdge・Chromeで最終確認してください。3D表示にはWebGL 2が必要です。

サイトの公開・デプロイは行っていません。GitHubから取得してパソコンに保存するアプリです。

## 開発者向け

`npm run build:standalone` で生成されたHTML・開き方・ライセンス表記をZIPに入れ、`preview` の成果物も更新してください。ソースがあるため、今後も設備や機能を追加できます。
