# 04_平面図作成（LPガス設備図面作成 V2）

Windows PC向けの、LPガス設備設置計画用平面図作成アプリ（V2）です。

**V1（`04_LPガス設備図面作成`）とは完全に独立したフォルダです。V1のファイルは変更しません。**

## 起動方法

1. このフォルダの **`04_平面図作成.html`** を Chrome（または Edge）で開きます。この1ファイルだけで動作します。開発用の `index.html` も同じ機能を持ちます。
2. V1を使う場合は、これまでどおり `04_LPガス設備図面作成\V1\index.html` を開いてください。

## 今回実装していること

- 左側：設備選択ボタン（配管を含む。配管は始点→終点クリックで直線配置）
- 中央：作図エリア（方眼、拡大・縮小、全体表示）
- 寸法入力ダイアログ（種類ごとに項目が異なる／未入力＝未確認可）
- 配置・選択・ドラッグ移動・矢印100mm移動・前面／背面・削除・寸法変更
- 平面図上の寸法表示
- **ビフォア／アフター**：現状図をコピーして変更案を作成し、左右比較できる
- 右上：日付・タイトル・名前（名前の初期値は「ニイミ産業」）
- **開く／保存／印刷**（保存はダウンロード。ファイル名は `日付_上から平面図_タイトル_名前.json`）
- 設備データと図面（配置）を分けたデータ構造（側面図連携を想定）
- V2専用のブラウザ内自動保存（V1の保存キーとは別）

## ビフォア／アフターの使い方

1. **ビフォア**で現状の図面を作る
2. **コピー作成**（またはアフター）でアフターページを作る（ビフォアの複製）
3. **アフター**で不要な設備を削除し、新しい設備を追加する
4. **比較**で左右に並べて確認する（比較中は編集不可）

### ビフォアの映し出し

アフターは、ビフォアを土台として映し出します。

- ビフォアで追加・移動・寸法変更すると、**まだアフターで触っていない設備**に反映されます
- ビフォアで削除すると、対応するアフター設備も削除されます（アフターで動かしていても連動削除）
- アフターで動かした／寸法を変えた設備は、その時点でビフォア追従から外れ、位置・寸法はアフター側のまま残ります
- アフターで消した設備は消え続けます（ビフォアには残ります）
- アフターだけで追加した設備はアフター専用です
- アフターを動かしてもビフォアは変わりません

- **コピー作成** … アフターがまだないときだけ表示。ビフォアを複製してアフターを新規作成します。
- **作り直す** … アフターがあるときだけ表示。アフターの変更を捨てて、いまのビフォアから作り直します（誤操作防止のため確認あり。「戻る」で直前に戻せます）。

## 保存・開く・印刷

- **保存** … JSONをダウンロード（例: `20261012_上から平面図_題名_ニイミ産業.json`）。ブラウザ内の自動保存も併用します。
- **開く** … 保存したJSONを読み込みます。
- **印刷** … いまのページ（比較中は左右）を平面図として印刷します。

## PDF保存（追加）

1. Before（ビフォア）、After（アフター）、Compare（コンペア／比較）から保存する画面を選びます。
2. 右上の「PDF保存」を押すと、A4横・1ページのPDFをダウンロードします。
3. Compareではビフォアとアフターが左右に並びます。日付・題名・名前も含まれます。

ファイル名には図面情報と「ビフォア」「アフター」「比較」が付きます。
インターネット接続や追加ソフトは不要です。図面は高解像度の画像としてPDFに収録されます。
PDFは閲覧・印刷用です。後から編集する図面は、従来の「保存」でJSONも保存してください。

## 設備アイコンの色

左側の設備アイコンは、配置する図形と同じ配色です。Beforeでは淡い色、Afterでは新規設備の濃い色に切り替わります。
